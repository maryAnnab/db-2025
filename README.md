# DB-Engineering 2025

> Engineering coursework projects focused on database systems and data management

## Overview
Collection of practical database projects completed during Computer Science degree program at WSIZ Bielsko-Biała (2025). Projects cover relational and NoSQL databases, data analysis, and Python integration.

## Tech Stack
- **Languages:** Python, SQL
- **Databases:** SQLite, PostgreSQL, MongoDB
- **Libraries:** pandas, pymongo, NumPy, Pydantic
- **Web Frameworks:** Flask, Django, FastAPI
- **Testing:** pytest, unittest
- **DevOps:** Docker, Poetry, conda
- **Cloud:** AWS, Azure
- **Monitoring:** Grafana, Prometheus
- **AI/ML:** AI frameworks
- **Tools:** Jupyter, Apache

## Key Topics Covered
- Database design and modeling
- SQL queries and optimization  
- Python database integration
- Data analysis and visualization
- NoSQL document stores

## Structure
Each project includes:
- Database schema/model design
- Implementation scripts
- Sample data and queries
- Documentation
